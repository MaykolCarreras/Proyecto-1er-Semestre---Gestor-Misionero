# Gestor Misionero
Esta app tiene como campo las organizaciones misioneras como Hearctry Missionary Society. Aunque por motivos de implementación todavía tiene algunos elementos faltos de realismo.

La siguiente app permite:
- Gestión de eventos
    - Ver/Añadir eventos en base a los recrusos disponibles

La siguiente app posee:
- Sistema de pool de recursos (semi-implementado. Ver (1) al final del README.md.)

# Eventos:
1. Entrega de recursos
2. Donación
3. Talleres
4. Conferencias

(1) Para la correcta interpretación del sistema de pool de recursos es necesario asumir que la organización repone los recursos gastados luego de cada evento. Esto ha sido necesario mientras se trabaja en otras funcionalidades. Es posible que en un futuro se mejore dicha funcionalidad.
